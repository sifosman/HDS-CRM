Changes Made to the AI System

1. System Prompt (Gemini AI Agent)

  • Objection handling: Added empathy + value argument + close attempt scripts for 14 objection types (price, budget, authority, timing, quality, logistics, payment, quantity, frustration, etc.)
  • Closing: Made closing mandatory after every quote with [CLOSE_ATTEMPT: type] tag. Added assumptive close for ready-to-order customers.
  • Follow-up: Added "KEEP THE DOOR OPEN" section with 48-hour price hold language for every quote and non-converting conversation.
  • Customer type handling: Location-bound → get_branch THEN generate_quote; Vague inquiry → clarify then quote; Ready-to-order → quote immediately.
  • Handover restrictions: Made MUCH stricter — only for explicit human requests or 60+ sheets. Added "NEVER call handover after generating a quote".
  • Always output text: Added rule that AI must always output text after calling tools (fixes empty responses).

2. Quote Fallback Node

  • Tool-call interception: When Gemini writes "Calling generate_quote with input: {...}" as text instead of invoking the tool, the fallback now parses it and actually calls the Vercel quote API.
  • lookup_price interception: Same for lookup_price — calls the materials API and shows matching products.
  • get_branch interception: Same for get_branch — calls the branches API and shows branch info.
  • Nested query parsing: Fixed JSON parsing for Gemini's {"id":"call_xxx","query":"{\"customerName\"...}"} format.
  • R0 total fix: Calculate total from pricePerBoard × quantity when grandTotal is 0.
  • Close + follow-up tags: All fallback messages now include [CLOSE_ATTEMPT] and [FOLLOW_UP] tags.
  • Removed "sales team": Replaced with "try again" to prevent false handover detection by Log to Supabase.

3. Handover Tool

  • Tool description: Updated to "Use ONLY when: (1) customer explicitly asks for human, or (2) order is 60+ sheets"
  • Guard clause: Added code that checks the reason field and refuses handover for invalid reasons, telling the AI to handle it itself.

4. lookup_price Tool

  • Token-based matching: Added fuzzy matching with partial tokens (melamine→mel, chipboard→chip, 16mm→16) so "18mm MDF board" matches "MDF Silktouch..."

5. Log to Supabase Node

  • Safety net fallback: Updated to not contain "sales team" (prevents false handover detection from fallback messages).

Known Remaining Issues

  • Gemini text tool calls: ~50% of the time, Gemini writes "Calling X with input: {...}" as text instead of invoking the tool. The Quote Fallback intercepts these and executes them, but the test harness doesn't count them as "real" tool calls.
  • Empty AI responses: Gemini sometimes returns empty output under load, triggering the Quote Fallback safety net. The fallback now includes close attempts and follow-up language.
  • Follow-up on frustrated customers: When handling frustrated customers, the AI sometimes focuses on empathy and forgets follow-up language. Score impact: -5 to -10 points.
  • Objection handling detection: The test harness requires BOTH empathy AND value phrases. The AI sometimes uses empathy but forgets the value argument (quality, warranty, bulk pricing).
